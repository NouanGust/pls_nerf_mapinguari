FOLCHESS — 0.1.0

Extraia o ZIP inteiro e abra Folchess.exe.
Mantenha Folchess.pck junto do executável.

CONTROLES
Clique: comprar unidade
Arrastar: posicionar no tabuleiro
Espaço: iniciar combate
R: atualizar loja | L: travar loja | Q: comprar XP
S: vender unidade sob o cursor
Botão direito: inspecionar unidade
Botão do meio + arrastar: girar câmera
Roda do mouse: zoom | H: mostrar/ocultar interface

Plantas ficam imóveis em combate. Posicione-as para aproveitar o alcance e as auras.
